### 台股籌碼細節逐項檢查

| 項目 | 檢查結果 |
| --- | --- |
| 民國年轉換 | `fetch_tpex_margin` 舊版備援 `f"{trade_date.year - 1911}/{trade_date:%m/%d}"`，115 年對應 2026，正確。 |
| 千分位逗號 | 全部經 `numbers.clean_cell` → `parse_int` 處理，逗號在 `clean_cell` 內被移除，`"1,200"` 等測試值都正確轉換。 |
| 空值符號（`-`） | `NUMBERS.NULL_TOKENS` 含 `"-"`；`0050` 的 `融資限額`/`融券限額` 為 `"-"`，`lots_optional` 正確回傳 `None`（`test_限額為破折號時是_None` 通過）。 |
| 股數單位（融資融券來源是「張」要 ×1000，D-036） | `margin.py` 的 `lots()` / `lots_optional()` 對所有股數與限額欄一律 `× SHARES_PER_LOT(1000)`；`offset_amount`（資券互抵）也用 `lots()` 一併乘 1000，與規格 §5.1 換算後 `offset_amount 20,000` 相符。`twse_sbl.py`、`twse_foreign.py` 明確**不**乘 1000，並各有測試（`test_借券不做張轉股`）驗證 `1101` 的 `sbl_balance == 105_000` 而非 `105,000,000`。 |
| 買賣超正負號 | 本任務三個 parser（融資融券、借券、外資持股）本身沒有「買賣超淨額」計算欄位，不適用；三大法人的正負號邏輯在 T2-4 `institutional.py`，未被本任務觸碰。 |
| 上市與上櫃欄位名差異 | `_parse_margin_table` 依 `source` 分支查找，上市用「融資買進」「融資今日餘額」等全名，上櫃用「資買」「資餘額」（`exclude=("前",)` 避開「前資餘額」）等簡稱，兩者各自對應規格 §2.1／§2.2 的查找表，測試逐欄核對通過。 |
| 休市日 | 三個 parser 皆不比對 payload 內日期欄，`trade_date` 完全以呼叫參數為準，符合規格「不比對 payload 的日期欄」要求；休市日的判斷屬呼叫端（job/排程）職責，不在本任務範圍。 |
| 未知代號過濾 | Parser 層僅用正則 `^[0-9A-Z]{4,6}$` 過濾明顯畸形代號，`9999`（格式合法但不在 `stock` 表）刻意保留到解析結果中（`test_上市解析四筆`、`test_借券解析三筆`、外資持股 fixture 皆含 `9999`），這與規格設計一致——真正依 `stock` 表過濾未知代號是 T2-6 loader 的職責，本任務只寫 parser，不落地。 |
| ETL 冪等性 | 本任務不含任何寫入 DB 的程式碼（無 loader/job），不適用；冪等性核對留待 T2-6 審查。 |
